# Illustrative source reconciliation

## Source precedence
Keep the latest valid revision of each external event and preserve its provider identifier. Reject conflicting or older revisions. Display which sources contributed to an asset assessment. Weather warnings describe a hazard area, whereas a maintenance record describes an asset condition; neither should silently overwrite the other.

## Operational reconciliation
GIS, maintenance and field operations records must resolve to the same installation identifier. Check existing assignments before creating work. If field information conflicts with stored metadata, request confirmation instead of declaring one source correct. Combine multiple active signals in the operator view without pretending they are statistically independent failure probabilities.
